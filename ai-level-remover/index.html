FAQs

Does removing metadata remove the AI label?

Yes. Platforms read hidden header metadata (C2PA, JUMBF, XMP, EXIF, and PNG text chunks) to detect AI labels. Stripping those metadata blocks removes those signals without altering pixels.

Does it reduce photo quality?

No. Metadata chunks are removed directly from JPEG, PNG, and WebP file headers without recompressing pixels.

What if there is a visible logo or text on the photo?

Use the Visual AI Eraser tab in the top menu to brush over any visible badge or text watermark.
